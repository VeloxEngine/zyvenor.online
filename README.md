# TechAI Insights — Static Website (HTML, CSS, JS)

A fast, responsive, and modern dark-mode AI technology publication website built with pure semantic **HTML5**, **Vanilla CSS**, and **Vanilla JavaScript**.

---

## 📁 Project Structure

```text
├── index.html                 # Homepage (Hero, AI Pillars, Featured Insights, Newsletter)
├── blog.html                  # Blog Listing ("Intelligence Hub" with real-time category filtering & search)
├── the-future-of-llms.html    # In-depth technical article with interactive share/copy
├── about.html                 # Mission, editorial scope, and research metrics
├── contact.html               # Interactive inquiry form with instant toast feedback
├── privacy.html               # Privacy Policy
├── terms.html                 # Terms of Service
├── disclaimer.html            # Legal & technical disclaimer
├── css/
│   └── style.css              # Custom dark-mode design system & typography
└── js/
    └── main.js                # Mobile navigation, search/filter, and form handling
```

---

## 🚀 How to Run

Because this is a pure static website with no compilation or build steps required:

### Option 1: Direct File Opening
Double-click `index.html` to open it in your web browser.

### Option 2: Local HTTP Server (Optional)
Run any local server of your choice:

```bash
# Python 3
python -m http.server 8080

# Or with Node
npx serve .
```

Open `http://localhost:8080` in your browser.
